# BSF Ventas 1.0

Aplicación para Windows 11 de 64 bits. No requiere Python ni conexión a Internet para trabajar.

## Instalación y actualización

Descarga **BSF-Ventas-Setup.exe**, cierra BSF Ventas si está abierto y ejecuta el instalador. No es necesario desinstalar la versión anterior. Los proveedores, artículos, informes, historial y ajustes se conservan. En otro ordenador se empieza con una base de datos vacía; las copias de seguridad permiten transferir los datos si se desea.

## Novedades

- Los informes nuevos proponen desde el primer día del mes actual hasta hoy.
- La rueda del ratón desplaza los artículos sin modificar cantidades, costes, fechas ni selectores cerrados. Arriba/Abajo recorren los campos de las filas; Enter avanza y Mayús+Enter retrocede.
- Los informes guardados se abren en vista previa. Cada fila ofrece Ver, Editar, Imprimir y Eliminar.
- Vista previa incorpora Imprimir, con selección de impresora y páginas en el diálogo de Windows.
- Los PDF exportados se abren automáticamente en la aplicación predeterminada.
- La importación individual confirma el resultado; la importación múltiple muestra un resumen verde (completa), naranja (parcial) o rojo (sin importar).
- Se mantienen la importación de catálogos XLS/CSV, los nombres de tienda, el historial de versiones, las copias de seguridad y los menús contextuales.
